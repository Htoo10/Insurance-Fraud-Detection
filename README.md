# Insurance Fraud Detection Using Machine Learning

## Project Overview

This project explores the application of machine learning techniques to insurance fraud detection. Using an insurance claims dataset, the project investigates patterns and characteristics that may help distinguish potentially fraudulent claims from legitimate ones.

## Objectives

- Explore and understand insurance claim data.
- Perform data cleaning and preprocessing.
- Analyse patterns and features associated with insurance fraud.
- Evaluate machine learning approaches for fraud detection.
- Compare model performance using appropriate evaluation metrics.

## Dataset

- Dataset: Fraud Insurance Oracle Dataset
- Records: 15,420
- Features: 33

The dataset contains information about insurance claims, policyholders, vehicles, accidents and claim characteristics.
